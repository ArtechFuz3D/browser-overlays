    Your link

    1. In OBS, add a Browser source.
    2. Paste your link into URL.
    3. Set width 600 and height 300. This matches the preview, so the position carries over.

    Your city and coordinates are stored in the link itself, so anyone who sees the link can see the location. Choose a larger nearby city if that matters to you. Weather data from Open-Meteo, free for non-commercial use. Wave and tide data uses Open-Meteo's marine models (including DWD), which request attribution.
